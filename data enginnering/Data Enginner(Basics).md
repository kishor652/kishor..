1\. What is SDLC?

&#x20; - It is an step by step process that teams to follow to plan ,build, test and maintain software

&#x20; -7 Phases:

&#x20;        1. planning -> Set goals , scope \& Budget

&#x20;        2. Requirement-> Capture What user Need

&#x20;        3. Design-> Blueprint the solution

&#x20;        4. Development-> Write the actual code

&#x20;        5. Testing-> Find \& fix the bugs

&#x20;        6. Deployment-> Release to real consumers/Users

&#x20;        7. Maintenance-> Support and Improve.



2\. What is Agile?

* Agile is software development methodology
* It is an mindset and set of practises for software development that embraces change and delivers value incrementally

&#x20;    and puts people and collaboration at the centre of every decision

* Agile promotes teamwork, collaboration, transparency
* Agile framework includes:

&#x20;                Scrum

&#x20;                Kanban

* &#x20;Scrum includes Product owner ,Scrum Master and Development Team
* &#x20;The development process is divided into short periods called sprints
* &#x20;A sprint commonly lasts between 1 and 4 weeks 



3\. Why do we prefer Agile Over Waterfall ?

* Waterfall follows a sequential approach, while agile is iterative and incremental
* In waterfall changes are difficult expensive after development begins
* In waterfall the complete product is generally delivered after all phases are completed
* Agile helps identify and fix problems earlier
* Agile is often preferred for projects that requires flexibility, faster delivery and continuous feedback

5\. What is CI/CD?

&#x20; 

* CI-Continuous Integration
* CD- Continuous Deployment/Delivery
* Continuous Integration means integrated code changes into a shared repository
* Developers regularly push their code to a version control system such as Git
* Continuous Delivery means keeping the application ready for release at any time
* Common CI/CD tools include Jenkins, Git hub, Azure
* Continuous Integration is used to Organize process.
* CI/CD reduces manual work in the software delivery process



6\. What is Git/GitHub?



* Git is an Version Control System used to track changes in source code
* It allows multiple developers to work on the same project.
* GitHub is an cloud repository
* Developers can **Push** their local code to GitHub
* Git add / is used to add the file to staging area
* Commit is used to make changes
* Push command used to move one to another file
* Git pull--getting information(cloud to local)
* Git push--- Pass information(Local to Cloud)



7\. What is Jenkins?



* Jenkins is an open source automation server widely used in develops
* Jenkins automatically build an application after developers push code
* Jenkins integrated with Git and git hub
* It is an pipeline defines the diff steps involve in build and deploy software
* Jenkins automates the process of building, testing and deploying software
* Jenkins uses plugin to add support for different tools and technologies
